## Overview

VANGO is a front-end application for a luxury watch retailer, fully migrated into a Single Page Application built with React and Vite. The UI is crafted with Tailwind CSS to deliver a premium, responsive shopping experience across desktop, tablet, and mobile.

The project covers the complete customer journey — from browsing collections to completing checkout — alongside a dedicated admin interface for store operations.

## Features

### Storefront
- Browse watch collections with filtering and product detail pages
- Save items to a favorites list
- Full checkout flow

### User Accounts
- Login and registration
- Password reset
- Profile management

### Admin Dashboard
- Order management
- Customer management
- Store oversight and administration

## Tech Stack

| Layer | Technology |

| Framework | React.js |

## Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) v18 or higher
- npm (or yarn / pnpm)

### Installation

```bash
# Clone the repository
git clone https://github.com/MouadSaber/vango.git
cd vango

# Install dependencies
npm install

# Start the development server
npm run dev
